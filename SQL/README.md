# 🗄️ SQL | Data Analytics & Business Intelligence

Bienvenue dans mon espace dédié aux projets **SQL et Data Analytics**.

Ce dépôt regroupe mes travaux pratiques réalisés autour de l’exploitation, de la structuration, du contrôle et de l’analyse de données avec **SQL Server et T-SQL**.

L’objectif de cet espace est de mettre en pratique une démarche complète d’analyse de données, depuis la **modélisation des données** et leur **chargement**, jusqu'au **contrôle de leur qualité**, à l’écriture de requêtes analytiques et à la production d’informations utiles à la décision.

## 🎯 Objectif

À travers ce dépôt, je développe et démontre ma capacité à :

- concevoir et exploiter des bases de données relationnelles ;
- manipuler des données avec **T-SQL** ;
- construire des requêtes analytiques ;
- utiliser `JOIN`, agrégations, sous-requêtes, CTE et fonctions de fenêtrage ;
- créer des indicateurs et KPI à partir des données ;
- contrôler la qualité et l’intégrité des données ;
- identifier et traiter les anomalies ;
- transformer des données brutes en informations exploitables pour l'analyse métier.

## 🔧 Technologies

- **SGBD :** SQL Server
- **Langage :** T-SQL
- **Outil :** SQL Server Management Studio (SSMS)
- **Version cible :** SQL Server 2019+

## 📂 Organisation

Les travaux sont organisés dans ce dépôt selon une progression structurée, avec pour objectif de couvrir différentes problématiques d'analyse de données et différents niveaux de complexité.

Chaque projet dispose de son propre environnement de travail, de sa documentation et de ses scripts SQL.

## 🚀 Démarche

Les projets suivent autant que possible une démarche similaire à celle utilisée dans un contexte professionnel :

**Modélisation → Création de la base → Chargement des données → Contrôle qualité → Nettoyage → Analyse SQL → Interprétation**

Cette approche permet de ne pas considérer SQL uniquement comme un langage de requête, mais comme un outil permettant de construire une chaîne d'analyse de données cohérente et reproductible.

## 📌 À propos

Ce dépôt fait partie de mon portfolio personnel et accompagne mon parcours de montée en compétences dans les domaines de la **Data Analysis**, de la **Business Intelligence** et de la **Data Science**.

> L'objectif est de privilégier des projets construits autour de problématiques métier concrètes plutôt que de simples exercices syntaxiques SQL.
