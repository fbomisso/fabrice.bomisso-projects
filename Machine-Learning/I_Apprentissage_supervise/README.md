# Apprentissage supervisé

Bienvenue dans la section **Apprentissage supervisé** de mon portfolio Machine Learning.

Ce dossier regroupe mes travaux consacrés aux méthodes d'apprentissage supervisé et présente leur organisation générale selon les principales familles de problèmes de prédiction.

## Organisation

La structure du dossier est organisée autour de deux catégories principales :

    01_Apprentissage_supervise/
    ├── 01_Classification/
    │   └── Projets de classification supervisée
    └── 02_Regression/
        └── Projets de régression supervisée

### 01_Classification

Cette partie regroupe les projets de classification supervisée, dont l'objectif est de prédire une variable catégorielle à partir de variables explicatives.

### 02_Regression

Cette partie regroupe les projets de régression supervisée, dont l'objectif est de prédire une variable quantitative continue à partir de variables explicatives.

## Organisation générale des projets

Chaque projet est organisé de manière indépendante et peut contenir, selon ses besoins :

- des notebooks d'analyse et de modélisation ;
- des données ;
- des visualisations ;
- des modèles entraînés ;
- des applications ;
- des fichiers de configuration et de dépendances.

Cette organisation permet de conserver une structure claire, cohérente et évolutive pour l'ensemble des travaux d'apprentissage supervisé.
